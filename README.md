# My-learning-journal

A personal blog documenting my journey from consuming tutorials to building real projects. This site serves as a public log of my growth in both code (Dev Notes) and mindset (Life Lessons).

The Build :

This isn't a template. It's a custom-built learning journal designed to be lightweight and fast.

Key Features :
- Dual-Category Layout: A "storefront" homepage featuring side-by-side columns for Dev Notes and Life Lessons on desktop, stacking cleanly on mobile.
- Mobile-First Navigation: Solved vertical stacking issues by swapping complex flexbox rules for a simple `inline-block` + percentage width strategy.
- Image Consistency: Used `object-fit: cover` to ensure all post teasers maintain uniform dimensions without distortion.
- Zero-Bloat Icons: Social links use native emojis for instant loading and zero external dependencies.

Tech Stack :

- Semantic HTML5
- Custom CSS3 (No frameworks)
- Responsive design via media queries

Project Structure :

The repo is modular. The homepage acts as a curated window, manually featuring the latest post from each category to keep the design intentional rather than automated.
